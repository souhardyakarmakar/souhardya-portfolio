# Demo websites

Twelve static HTML/CSS/JavaScript concepts by Souhardya Karmakar. Each page is an independent fictional interface; no build step or backend is required.

- `index.html` is the demo hub.
- Each folder contains one demo page.
- `shared/` contains the common visual effects, demo profile UI, and generated SVG artwork.
- The French Cat mark is served from `logo.png` in this folder.
- Optional demo profiles use a display name only, held in memory for the current page. Demo pages do not ask for email addresses or passwords, write profile data to browser storage, or send data to a server.
- Call-to-action panels are display-only; they do not request contact details.
- Carts, dashboards, forms, and scans are illustrative only; they do not complete purchases, send messages, provide financial advice, or inspect devices.

Run the portfolio root with a local web server to try the links as they work on GitHub Pages.
