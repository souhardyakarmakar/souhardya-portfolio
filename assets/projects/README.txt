PROJECT MEDIA

Put project preview images and demo videos in this folder.

Example paths to add in collections.js:
assets/projects/my-project.png
assets/projects/my-project-demo.mp4

In the marked project entry, set image to the image path and/or video to the
video path. MP4 and WebM videos are recommended. Keep file names simple and use
the exact same spelling and extension in collections.js.
